Grammy Capstone Project

Analyzed website performance data to uncover user behavior, identify trends, and develop data-driven recommendations.

Excel • Data Analysis • Data Visualization • PivotTables • Formulas • A/B Testing

Interactive Workbook

Project Overview

This project analyzed website performance for Grammy.com and RecordingAcademy.com to evaluate user engagement and determine whether separating the two websites improved the user experience. Using Excel, I analyzed website traffic, pages per session, bounce rate, average time on site, mobile usage, and A/B testing results to identify changes in visitor behavior and develop a business recommendation.

Website Performance Analysis

I compared engagement metrics across Grammy.com and RecordingAcademy.com to understand how visitors interacted with each website. The analysis included pages per session, bounce rate, average time on site, traffic patterns, and mobile usage.

Experiment Analysis

I also evaluated the results of an A/B test by comparing visitor and CTA click data between the control and test groups. The experiment was used to determine whether the test version produced a statistically significant improvement.

Key Findings

2.78 Pages

Recording Academy Engagement

RecordingAcademy.com averaged 2.78 pages per session with a 33.7% bounce rate and 128.50 seconds average time on site.

2.25 Pages

Grammy.com After Split

Grammy.com increased from 1.86 to 2.25 pages per session after the websites were separated.

73.7%

Mobile Traffic

Mobile visitors represented 73.7% of total website traffic, making mobile usability an important part of the overall user experience.

~1.39M Visitors

Grammy Event Traffic

A Grammy Awards live-event day generated approximately 1,389,590 visitors compared with roughly 32,388 visitors on a typical day.

3.85%

Test Conversion Rate

The test group generated 158 CTA clicks from 4,099 visitors, producing approximately a 3.85% conversion rate.

3.13%

Control Conversion Rate

The control group generated 119 CTA clicks from 3,797 visitors, producing approximately a 3.13% conversion rate.

Recommendations

Based on the analysis, I recommended maintaining the separate Grammy and Recording Academy websites while continuing to improve the mobile experience. The website split showed improvements in important engagement metrics while allowing each site to maintain a more focused purpose for its audience.

I also recommended increasing awareness of Recording Academy programs and services throughout the year rather than relying primarily on Grammy-related events.

One approach would be to highlight Recording Academy initiatives alongside Grammy content on the homepage, allowing the Grammy Awards to attract visitors while exposing those users to additional Recording Academy content.
