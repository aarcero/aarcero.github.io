UFO Sightings Analysis

Used Tableau to clean and transform UFO sighting data and visualize geographic and observational patterns across the dataset.

Tableau • Calculated Fields • Data Visualization

Project Overview

This project explored UFO sighting data using Tableau. The goal was to transform the raw location information into fields that could be analyzed more effectively and then create visualizations that made patterns in the sightings easier to identify.

Data Preparation

The original location data required additional preparation before it could be used effectively in the visualizations. I created calculated fields in Tableau to extract and standardize geographic information from the dataset.

Functions such as SPLIT were used to separate location information, allowing state values to be isolated from the original field. This made it possible to compare sightings geographically instead of relying on the original combined location values.

Analysis

After preparing the data, I created Tableau visualizations to examine how UFO sightings were distributed across different locations. This made it possible to compare states and identify areas with particularly high numbers of reported sightings.

The project also explored characteristics of the sightings beyond geography, including patterns associated with when sightings occurred and the reported shapes of the observed objects.

Key Findings

#1

California

California had the highest number of UFO sightings in the analyzed data.

#2

Florida

Florida appeared among the states with the largest number of reported sightings.

#3

Texas

Texas was also one of the leading states by total reported UFO sightings.

Visualization Approach

Tableau was used not only to visualize the dataset but also to transform it. Calculated fields allowed information contained inside larger text fields to become separate dimensions that could be used in charts and geographic comparisons.

The resulting visualizations made it easier to compare sightings by state and explore additional patterns involving country, month, reported shape, and time of day.

Takeaway

The analysis showed that reported UFO sightings were not evenly distributed geographically. California, Florida, and Texas appeared most frequently among the states in the dataset, demonstrating how geographic visualization can quickly reveal concentrations that are difficult to identify from raw records alone.

Skills Applied

Tableau, calculated fields, data cleaning, SPLIT functions, geographic analysis, data transformation, and data visualization.
