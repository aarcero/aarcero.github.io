Data Visualization Storytelling

Built Tableau visualizations across global height, music sales, and video game datasets to communicate patterns using maps, trend charts, and categorical comparisons.

Tableau • Data Visualization • Data Storytelling

Project Overview

This project focused on selecting visualizations that matched different types of data and analytical questions. I worked with three separate datasets covering global average height, historical music sales, and video game sales.

Because each dataset represented information differently, I used different visualization techniques to communicate the patterns found in each one.

Global Height Analysis

I analyzed global patterns in average height and used a choropleth map to visualize geographic differences between countries.

Mapping the data geographically made differences between countries easier to identify than they would have been from reviewing the underlying values alone.

Historical Music Sales

I analyzed historical music sales using a line chart to show how sales changed over time. The time-based visualization allowed increases, decreases, and broader changes in music sales to be communicated as a trend.

Video Game Sales

I also analyzed video game data to compare top-selling genres. A bar chart was used to make differences between the categories easy to compare visually.

Visualization Approach

A major focus of the project was matching the visualization to the structure of the data. Geographic data was represented through a choropleth map, historical data through a line chart, and categorical data through a bar chart.

Using different chart types helped communicate each dataset in a way that emphasized the most relevant relationship rather than applying the same visualization to every analysis.

Project Takeaway

This project demonstrated how visualization choice affects the way data is communicated. Maps can emphasize geographic differences, line charts can show change over time, and bar charts can make categorical comparisons easier to understand.

Working across three unrelated datasets also gave me experience adapting my visualization approach to the question being asked instead of relying on one chart type for every problem.
