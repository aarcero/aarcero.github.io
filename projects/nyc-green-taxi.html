NYC Green Taxi Analysis

Analyzed New York City Green Taxi trip and fare data to explore patterns in taxi activity using a large real-world transportation dataset.

Data Analysis • Data Visualization • Transportation Data

Project Overview

This project used New York City Green Taxi data to explore transportation activity through trip and fare information. The dataset provided an opportunity to work with real-world transportation records and examine how individual taxi trips could be transformed into useful visual analysis.

Trip Data Analysis

I examined trip information within the Green Taxi dataset to explore patterns in taxi activity. Rather than reviewing individual records by themselves, the data was organized and visualized so that broader transportation patterns could be identified more easily.

Fare Analysis

Fare information was another major component of the analysis. I used data visualization to examine NYC taxi fares and make comparisons across the transportation data.

Working With Real-World Data

The project provided experience analyzing a large transportation dataset containing many individual trip records. Working with this type of data required focusing on the variables that were most useful for answering questions about taxi activity and presenting those results visually.

Visualization Approach

Data visualization was used to turn individual taxi records into comparisons that were easier to interpret. This allowed trip and fare information to be viewed at a broader level instead of analyzing each taxi record independently.

Project Takeaway

The project demonstrated how a large real-world transportation dataset can be explored through visual analysis. By examining trip and fare information, the raw Green Taxi records could be organized into a form that made patterns in taxi activity easier to understand.
